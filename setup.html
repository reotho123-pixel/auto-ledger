⌨️ 快捷指令「记一笔」安装引导

复制支付通知 → 轻点一下 → 金额/商户/分类/时间自动填好 → 点「保存这笔」。全程约 3 秒。

✅ 开始前确认
你正在用 iPhone 的 Safari 看到本页，说明网络没问题。如果是在微信里打开的，请点右上角「···」→ 在 Safari 中打开。此引导只需要做一次。
🛠️ 四步建好快捷指令（约 2 分钟）
1
打开 iPhone 自带 快捷指令 App → 底部「快捷指令」→ 右上角 ＋ 新建。
2
点 添加操作，按顺序搜索并添加下面 4 个动作（顺序不能错）：
① 获取剪贴板
② URL 编码（输入自动接上一步，不用改）
③ 文本：先复制下面这行网址粘贴进输入框，然后点输入框下方/长按选 选择变量，把第②步「URL 编码」的结果变量接到网址末尾（或直接把变量拖到末尾）

④ 打开 URL（输入自动接上一步）
3
点顶部长标题 → 改名为 记一笔 → 右上角「完成」。
4
先复制下面这段示例支付文字，再运行一次「记一笔」验证：Safari 应自动弹出且金额 25、商户 瑞幸咖啡 已填好。测完去「明细」把这条删掉即可。
✨ 让它更好用：轻点背面两下
设置 → 辅助功能 → 触控 → 拉到最底 轻点背面 → 轻点两下 → 选快捷指令「记一笔」。以后复制完支付通知，敲两下手机背面就自动记账。
📱 日常怎么用
  • 微信：支付后点开「微信支付」服务通知 → 长按文字 复制（通知栏也可以）→ 敲两下背面 → 保存
  • 支付宝：账单详情页复制商家/金额信息，或用「数据」页导 CSV 批量补
  • 银行消费短信：建议另建一条「收到信息」自动化（配方一），实现零操作
🩹 不对劲时看这里
  • 打开后提示「没识别出金额」→ 剪贴板里不是支付文字，重新复制
  • 打开的是 404/空白页 → 检查第③步网址是否完整（务必用上面的复制按钮）
  • 每笔都要点一下「保存这笔」→ 这是防误识别/重复记账的确认，故意的
  • 数据存在手机本机浏览器，换浏览器/清 Safari 数据会丢 → 记得每月「数据 → 导出备份」
